## Notes for how to style figures
- in general make sure to use large enough font, larger than you might think. These figures have to be put on papers and presentations so the font needs to be readable.
- make sure any legends are descriptive but not overly descriptive
- avoid titles, opt for captions in the actual medium instead (that is, on the presentation or on the paper)
- no gridlines unless absolutely necessary
- report chi square and chi square probability on the figures
- report uncertainty on the figures where appropriate
- for error bars, our professor prefers that the error bars do not have the horizontal lines at the tips. however, this is not a big deal. if it sacrifices readability / visibility, leave them in.
