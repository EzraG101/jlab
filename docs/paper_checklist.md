# Paper Checklist

Use this checklist before submitting the Junior Lab paper. The original grading categories are included where specified.

## Style & Structure (15%)

- [ ] Use the Junior Lab LaTeX template.
- [ ] Keep the paper to **3.5-4 pages**.
- [ ] Include the required sections in the expected order:
  - [ ] Title
  - [ ] Author list
  - [ ] Abstract
  - [ ] Introduction / motivation
  - [ ] Theory / physics
  - [ ] Detector description
  - [ ] Calibration / data analysis
  - [ ] Error analysis
  - [ ] Results
  - [ ] Discussion / conclusions
  - [ ] Acknowledgements
  - [ ] References
- [ ] Do **not** include a generic outline section.
- [ ] Run the paper through a spell checker.
- [ ] Make sure figures remain clearly readable when printed in black and white.
- [ ] Embed figures near the relevant discussion in the text, rather than collecting them at the end.
- [ ] Give every plot complete visual information:
  - [ ] Axis labels
  - [ ] Axis titles
  - [ ] Units
  - [ ] Legends for multiple data sets or fits
- [ ] Provide references for any outside material.
- [ ] Avoid first person singular.

## Introduction, Motivation, And Theory (15%)

- [ ] Explain the relevant physics clearly and briefly.
- [ ] Define the goals of the experiment clearly.
- [ ] Quote or derive the relevant equations.
- [ ] Define all variables and acronyms when introduced.
- [ ] Avoid lengthy derivations unless they are original and directly relevant.

## Experimental Setup, Procedure, And Raw Data (35%)

- [ ] Include a drawing or schematic of the experiment.
- [ ] Identify and describe the main pieces of equipment.
- [ ] Briefly explain the detector physics.
- [ ] Show example raw data, or all raw data where appropriate, as a figure.
- [ ] Describe the experimental procedure.
- [ ] Describe detector calibrations.
- [ ] Explain the analysis procedure step by step.

## Data Analysis, Error Analysis, Discussion, And Conclusions (35%)

- [ ] Show analysis results as figures where appropriate.
- [ ] Clearly categorize all contributions to uncertainty, for example:
  - [ ] Statistical vs. systematic uncertainties
  - [ ] Point-to-point errors vs. scale errors
- [ ] Calculate and report statistical uncertainties properly.
- [ ] Report fit results and fit uncertainties.
- [ ] When appropriate, report chi-squared values and fit probabilities.
- [ ] List sources of systematic uncertainty in order of priority, including relevant sources such as:
  - [ ] Calibration procedure
  - [ ] Equipment resolution
  - [ ] Analysis method
  - [ ] Other experiment-specific effects
- [ ] Provide quantitative estimates for all systematic uncertainty contributions.
- [ ] Propagate all quantitative uncertainties to the final result.
- [ ] Quote the final result with its uncertainty.
- [ ] Compare final results to accepted values where applicable.
- [ ] Discuss deviations from accepted values quantitatively in terms of known uncertainties.
- [ ] Discuss the physics implications of the results.
- [ ] Do **not** end with a "this is what we could have done better" section.
