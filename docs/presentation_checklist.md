# Presentation Checklist

Use this checklist before giving the Junior Lab presentation.

## Style & Structure

- [ ] Practice the presentation in full before presenting.
- [ ] Keep the presentation to **15 +/- 1 minutes**.
- [ ] Include the expected presentation components:
  - [ ] Title
  - [ ] Introduction / motivation
  - [ ] Theory / physics
  - [ ] Detector description
  - [ ] Calibration / data analysis
  - [ ] Error analysis
  - [ ] Results
  - [ ] Discussion
  - [ ] Summary / conclusions
- [ ] Use a specific title, not only the generic experiment name.
- [ ] Do **not** include a generic outline slide.
- [ ] Run the slides through a spell checker.
- [ ] Include slide numbers.
- [ ] Make sure figures and text are readable from about 6 feet away on a laptop screen.
- [ ] Place figures deliberately so the slide layout feels intentional.
- [ ] Give every plot complete visual information:
  - [ ] Axis labels
  - [ ] Axis titles
  - [ ] Units
  - [ ] Legends for data sets and fits
- [ ] Provide references for outside figures next to the figures themselves.
- [ ] Avoid ending with a "this is what we could have done better" section.
- [ ] Avoid lengthy text blocks or paragraphs on slides.
- [ ] Keep visual conventions consistent across the full presentation:
  - [ ] Colors
  - [ ] Markers
  - [ ] Labels
  - [ ] Variable names
- [ ] Remove unnecessary grid lines and plot titles from figures unless they serve a clear purpose.

## Introduction, Motivation, And Theory

- [ ] Explain the relevant physics clearly and briefly.
- [ ] Define the goals of the experiment clearly.
- [ ] Quote or derive the relevant equations.
- [ ] Define all variables and acronyms when introduced.
- [ ] Avoid lengthy derivations unless they are original and directly relevant.

## Experimental Setup, Procedure, And Raw Data

- [ ] Include a drawing or schematic of the experiment.
- [ ] Use labeled pictures where they help clarify the setup.
- [ ] Identify and describe the main pieces of equipment.
- [ ] Briefly explain the detector physics.
- [ ] Show examples, or all relevant examples, of raw data and intermediate analysis results as figures.
- [ ] Describe the experimental and data-taking procedure.
- [ ] Describe detector and data calibration procedures.
- [ ] Explain the analysis procedure step by step.

## Data Analysis, Error Analysis, Discussion, And Conclusions

- [ ] Show analysis results as figures where appropriate.
- [ ] Clearly categorize all contributions to uncertainty.
- [ ] Calculate and report statistical uncertainties properly.
- [ ] Report fit results and fit uncertainties.
- [ ] When appropriate, report chi-squared values and fit probabilities.
- [ ] List sources of systematic uncertainty in order of priority.
- [ ] Provide quantitative estimates for all systematic uncertainty contributions.
- [ ] Avoid non-quantitative speculation about unknown errors.
- [ ] Propagate all quantitative uncertainties to the final result.
- [ ] State final results and uncertainties clearly.
- [ ] Compare final results to accepted values where applicable.
- [ ] Discuss deviations from accepted values quantitatively in terms of known uncertainties.
- [ ] Discuss the physics implications and lessons from the experiment.
